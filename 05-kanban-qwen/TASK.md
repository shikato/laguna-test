# 課題1: カンバンボード（Trello風）

このディレクトリ（05-kanban-qwen/）に、ビルド不要で動作するカンバンボードWebアプリを実装してください。

## 技術制約
- 素のHTML/CSS/JavaScriptのみ。外部ライブラリ・フレームワーク・CDN読み込みは一切禁止
- ビルド工程なし。`index.html` をブラウザで開くだけで動作すること
- ファイル構成は `index.html` / `style.css` / `app.js` の3ファイルとすること
- このディレクトリの外のファイルには触れないこと

## 機能要件
1. カラム: 初期状態で「未着手」「進行中」「完了」の3カラム。カラムの追加・名前変更・削除ができる
2. カード: 各カラムにカードを追加・編集・削除できる。カードはタイトル、詳細説明、ラベル色（5色から選択）、期限日を持つ
3. ドラッグ&ドロップ: HTML5 Drag and Drop APIでカードをカラム間・カラム内で移動できる
4. 期限表示: 期限切れのカードは赤系の視覚的強調を行う
5. 永続化: すべての状態をlocalStorageに保存し、リロード後も復元される
6. 検索: キーワード入力でカードのタイトル・説明を対象に絞り込み表示できる

## UI要件
- カラムは横並びで画面幅を活用するレイアウト（ワイド画面で中央に狭く寄せない）
- 画面幅が狭い場合は横スクロールまたは折り返しで破綻しないこと
- 日本語UI

## 完了条件
- 上記機能がすべて動作すること
- ブラウザのコンソールにエラーが出ないこと
