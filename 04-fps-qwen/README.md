# 課題4: DoomライクFPS（Qwen3.8-27B）— 検証記録

[Qwen3.8-27B](https://huggingface.co/unsloth/Qwen3.8-27B-GGUF)（Alibaba、27B dense、UD-Q4_K_M量子化）による [03-fps](../03-fps/) と同一仕様のFPS実装。コードはすべてQwenが生成・修正したもので、人手による修正はしていない。

**結果: 初回実装14分06秒でタイトル画面付きの動作物が起動。操作体系統一の1ラウンドのみで完成（Lagunaの修正13ラウンドと対照的）**

## 実行環境

| 項目 | 内容 |
|---|---|

| エージェント | opencode 1.18.23（32K ctx） |

## セットアップで踏んだ問題（モデル能力とは別の知見）

- 旧llama.cpp（2026-03ビルド）はQwen3.8のハイブリッドSSM層に未対応（`missing tensor 'blk.64.ssm_conv1d.weight'`）→ 要リビルド
- **思考モード有効のままだと、opencodeのagenticループが機能しない**（思考が出力予算を食い潰しツール呼び出しに到達せず、Q8で35分・Q4で17分空転）。`enable_thinking:false` が必須だった
- Q8_0は7.5 tok/s（帯域律速）。Q4_K_Mで約12 tok/s
- opencodeセッションがコンテキスト17Kトークン付近で無通信ストールする事象が2回（強制終了→新規セッションで続きから復旧）
