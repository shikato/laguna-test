# 課題4: DoomライクFPS — Three.js（Qwen3.8-27B比較用、課題3と同一仕様）

このディレクトリ（04-fps-qwen/）に、Three.jsを使った一人称視点シューティングゲームを実装してください。

## 技術制約
- **Three.js** をCDNのimport map（jsDelivr等）で読み込むこと。バージョンは明示的に固定する
- Three.js以外の外部ライブラリは禁止。物理エンジンも禁止（衝突は自前の簡易判定でよい）
- ビルド工程なし。`index.html` をブラウザで開くだけで動作すること
- ファイル構成は `index.html` / `main.js` の2ファイルとすること
- **外部アセット（画像・音声・モデルファイル）の読み込みは禁止**。色・プロシージャル生成のみで表現すること
- このディレクトリの外のファイルには触れないこと

## 機能要件
1. 視点・操作: 一人称視点。WASDで移動、マウスで視点回転（Pointer Lock API、クリックでロック開始）、左クリックで射撃
2. レベル: 2次元グリッド配列で定義した迷路状マップ。壁はBoxGeometry、床と天井は平面。高低差なし
3. 壁衝突: プレイヤーは壁をすり抜けられない（グリッドベースの判定でよい）
4. 敵: 5体。プレイヤーに向かって直進してくる単純AI（壁は考慮しなくてよいが、壁にめり込んで見えなくならないようにすること）。常にカメラの方を向くビルボード（平面）で表現し、Doom風にする
5. 敵との接触: プレイヤーにダメージ。一定時間の無敵時間を設けて連続ダメージを防ぐ
6. 射撃: Raycasterによるヒットスキャン。敵はHP2、撃破でスコア加算と簡易エフェクト（消滅演出）
7. HUD: HP・残弾・撃破数をDOMオーバーレイで常時表示。残弾は30発、Rキーでリロード
8. 勝敗: 敵を全滅させたらクリア画面、HP0でゲームオーバー画面。いずれもキー入力でリスタート
9. 照準: 画面中央にクロスヘア表示

## 対象外（実装しないこと）
- 武器切替、サウンド、テクスチャ画像、複数ステージ、ミニマップ

## UI要件
- 日本語UI（クリア/ゲームオーバー等の表示）
- 画面はブラウザウィンドウ全体を使用

## 完了条件
- 上記機能がすべて動作すること
- ブラウザのコンソールにエラーが出ないこと
